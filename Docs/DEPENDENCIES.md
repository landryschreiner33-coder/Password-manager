# Dependency provenance

## App dependency

libsodium 1.0.22 provides Argon2id v1.3 through `crypto_pwhash_argon2id`, explicitly selecting algorithm 1.3. The app uses one lane, a 16-byte salt and a 32-byte output. No default algorithm identifier that may change with releases is used. AES-GCM is provided by Apple CryptoKit.

The complete unmodified `Clibsodium.xcframework` is vendored from the maintained official Swift distribution, `https://github.com/jedisct1/swift-sodium`, release 0.11.0, exact commit `cfd195c76882aa9b997560ca7cb95d72fbf5db00` (2026-04-09). Its headers report version 1.0.22; it contains a macOS arm64/arm64e/x86_64 library. The local package uses the binary artifact directly, without importing the distribution's newer cross-platform Package.swift manifest. This keeps our project on Swift tools 5.9 / Xcode 16 or later. No package downloads or floating references are required.

All vendored bytes were compared with the pinned upstream Git checkout retrieved over HTTPS, then SHA-256 pinned in `sodium-checksums.json`. `Scripts/check-source.py` verifies those pins. This establishes source provenance and local integrity, not a reproducible build of the precompiled Apple libraries. Independently verify/rebuild the framework from the matching libsodium source before high-assurance release. Both libsodium's ISC license and the Swift distribution's license are in `Core/Vendor` and must accompany distribution.

Matching libsodium source release: `https://github.com/jedisct1/libsodium`, tag `1.0.22-RELEASE`, commit `77e1ce5d6dee871c49ef211222ba18ef0c486bda`. It is used for Linux validation outside the app checkout; the Mac artifact cannot execute on Linux.

## Independent reference test fixture

`Scripts/ReferenceArgon2` is the PHC reference implementation from `https://github.com/P-H-C/phc-winner-argon2`, commit `f57e61e19229e23c4445b85494dbf7c07de721cb` (2021-06-25). It is not linked into the app. Required source files and the upstream test harness are unchanged; `argon2-checksums.json` pins them. Their included license permits CC0 or Apache-2.0. `Scripts/check-argon2.sh` runs the upstream vectors. The XCTest KDF fixture independently compares libsodium output against a 64 MiB/three-pass/one-lane vector generated by this reference implementation.

Authoring-only syntax tooling (not an app dependency): tree-sitter 0.25.2 and tree-sitter-swift 0.7.4, installed under `/tmp`. Parsing is not Swift type checking or Apple API validation.
